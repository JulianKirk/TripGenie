## Evidence status language

- **Verified** means the linked GitHub object or repository file was checked on
  4 September 2026.
- **Source only** means implementation or configuration exists, but it is not
  execution proof.
- **Pending manual capture** means no qualifying evidence is committed or linked
  yet. The report must retain this label until a team member performs and records
  the stated procedure.
- **Excluded** means the item must not be presented as delivered evidence.

Do not convert source code, a green component workflow, or a merged Compose
configuration into a claim that the integrated application was run locally.
Do not claim showcase attendance or contribution beyond the verifiable GitHub
links in the evidence register.

# Choosing accommodation

How TripGenie describes and searches accommodation listings. Every listing
belongs to the accommodation catalogue; the AI assistants read it but never
invent listings that are not in it.

## Accommodation types

Each listing has exactly one type: hotel, hostel, apartment, resort,
guesthouse, or camping. A hostel suits budget travellers who are happy to
share rooms, an apartment suits groups or longer stays that want a kitchen,
and a resort bundles facilities on one site. Camping listings usually have no
room details, because room and bed counts do not apply to a campsite.

## Rooms and beds

A listing may carry room details: the number of rooms, the number of beds,
and the bed types offered. Bed types are single, double, queen, king, bunk,
and sofa bed. A family or group should filter on a minimum room count or a
minimum bed count rather than on the type alone, because an apartment and a
guesthouse can both sleep six.

## Ratings and amenities

A rating is a number from 0 to 5, where 5 is the best. Searches can set a
minimum and a maximum rating. Amenities are a plain list such as wifi, pool,
or parking. A search for several amenities matches only the listings that
offer every one of them.

## Location: country and city

Every listing sits in a country and a city taken from the shared TripGenie
reference data, plus an optional street and street number. A city filter
needs a country as well, because the same city name can exist in more than
one country, so a search for Sydney must also say Australia.

## Availability status

A listing is available, unavailable, or sold out. Available listings can be
booked for new stays. A sold out or unavailable listing still appears in
search results so that it can be compared, so filter on availability status
when only bookable listings are wanted.
